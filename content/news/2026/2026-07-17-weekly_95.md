## Enhancements and Fixes in 4diac IDE

- **Replay Debugging**
  - Added support for replay debugging across multiple devices
  - Enabled debugging of selected resources within a device
  - Improved timeline handling:
    - Corrected branch calculation during timeline resizing
    - Fixed edge cases when removing events
  - Improved cleanup when closing replay debugging resources
- **Structured Text & Validation**
  - Fixed duplicate and stale diagnostics for Structured Text resources with query parameters
  - Improved collision validation messages for FB pin labels
  - Fixed FB shape helper to correctly calculate maximum pin label sizes
- **Platform & Maintenance**
  - Updated the target platform to Eclipse 2026-09
  - Restored GitLab settings removed in an earlier change


## Enhancements and Fixes in 4diac FORTE

- **Management Command Processing**
  - Continued refactoring of the management command infrastructure:
    - Introduced a dedicated `CommandScanner`
    - Reworked `CommandParser` for improved XML validation
    - Migrated boot file loading to the new parser
    - Eliminated unnecessary memory allocations and buffering
    - Optimized XML unescaping
  - Added comprehensive unit tests for the new command parser and fixed several related issues


## Enhancements and Fixes in 4diac Documentation

- Updated the replay debugging documentation to reflect the latest capabilities.


Many thanks to all contributors for their work and their feedback!
