## Enhancements and Fixes in 4diac IDE

- **Architecture & Dependencies**
  - Reduced dependencies on the main UI plugin by moving shared utilities and UI-specific classes to more appropriate plugins
  - Removed GEF and UI-specific classes from the main model
  - Cleaned up utility and plugin dependencies
- **Editors & Usability**
  - Fixed scaling issues in the Service Sequence Editor when switching tabs
  - Improved handling of documentation links to avoid UI deadlocks
  - Made pin name handling case-insensitive
  - Improved ST validation for `ELSEIF` conditions
- **Runtime & Export**
  - Fixed missing adapter initial values when exporting composite FBs for forte-ng
  - Added missing library model dependencies
- **Function Blocks & Libraries**
  - Corrected parameter descriptions for `F_DIVTIME` and `F_MULTIME`
  - Cleaned up obsolete members from Revolution Pi and Wago bus adapter definitions
  - Added namespace information to Wago definitions



Many thanks to all contributors for their work and their feedback!
