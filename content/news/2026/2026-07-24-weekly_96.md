## Enhancements and Fixes in 4diac IDE


- **Debugging & Evaluation**
  - Added support for breakpoints on ECC states
  - Added toggle watchpoint functionality
  - Improved interpreter execution:
    - Correctly applies data outputs in interpreter networks
    - Tracks explicitly initialized variables during evaluation
    - Uses concrete values for runtimes and watches
- **Project & Library Management**
  - Introduced a new library provider infrastructure
  - Enhanced the Manage Library wizard:
    - Integrated validation, preview, and pending changes
    - Added progress monitoring
  - Refactored project creation into a dedicated `ProjectCreator`
- **Model & Refactoring**
  - Introduced abstract base classes for ECC states, actions, and FB types
  - Added extensive automated tests for FB type and structured data renaming and moving across nested subapplications
  - Improved rename handling for container variable declarations
- **Editors & UI**
  - Introduced dialogs for editing sparse initial values of structs
  - Improved error messages and property section stability
  - Updated Trace Compass and reduced dependencies on internal Mylyn APIs
  - Simplified the FBT importer and removed obsolete dialogs and unused methods
- **Validation & Miscellaneous**
  - Improved validation for container variable declarations
  - Removed legacy OCL builder integration from project creation
  - Added the missing Wago636 function block for the 3.0 library


## Enhancements and Fixes in 4diac FORTE

- **EtherCAT**
  - Continued the EtherCAT integration with the second development stage:
    - Added EtherCAT controller, bus, device, coupler, module, and adapter function blocks
    - Introduced configuration structures and module management infrastructure
    - Improved architecture for device configuration and ESI handling


## Enhancements and Fixes in 4diac Documentation

- Improved replay debugging documentation by clarifying terminology and workflow steps.


Many thanks to all contributors for their work and their feedback!
