## Enhancements and Fixes in 4diac IDE

- **Library Management**
  - Introduced the first redesign of the Manifest Editor:
    - Grouped dependencies for improved readability
    - Added version range validation and error highlighting
    - Added refresh and library management actions
    - Restricted editing where appropriate
    - Added marker navigation support
  - Moved the Library Preference page into the library UI plugin
  - Refreshed the Manifest Editor after library builds
  - Removed obsolete library management code
- **Simple Function Blocks**
  - Added an event action section for Simple FB types
  - Added model validation for Simple EC states
  - Improved editing of event actions
  - Simplified Simple EC state commands
- **Replay Debugging**
  - Automatically opens the state comparison view when adding new comparison states
- **Editor & Validation**
  - Improved handling of invalid FBs and missing pins
  - Fixed drag-and-drop handling for missing templates
  - Improved robustness and code quality through various cleanup and refactoring efforts
- **Build & Maintenance**
  - Removed obsolete resources and resolved additional Sonar findings


## Enhancements and Fixes in 4diac Documentation

- Reworked tutorials 4 and 5 with new images.


Many thanks to all contributors for their work and their feedback!
