This release focuses on stability, usability, and reliability, delivering numerous improvements across the property sheets, Structured Text editor, validation, export process, and type refactoring.

## Highlights

- Improved scrolling and rendering of property sheet tables, especially on Windows.
- More reliable type renaming while preserving error markers and member access information.
- Better Structured Text editing through improved function call type resolution and validation.
- More robust export builds during file refactoring.
- Reduced false-positive validation warnings for instances connected via adapters.
- Various UI fixes, API updates, and general maintenance improvements.

While this is a maintenance release, these improvements make everyday engineering with 4diac IDE smoother and more reliable.


As always, we appreciate the feedback and contributions from our community. If you encounter issues or have ideas for improvements, please let us know through our issue tracker or discussion channels.

Happy engineering!
