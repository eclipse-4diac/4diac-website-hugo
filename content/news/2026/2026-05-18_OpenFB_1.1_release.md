We are pleased to announce the release of **OpenFB**, a new open-source **IEC 61499** runtime for Python. The project source code is available on GitHub: [OpenFB](https://github.com/rtsoft-sdc/OpenFB).

**OpenFB** is a Python-powered IEC 61499 runtime compliant with latest **4diac IDE**. It acts as a lightweight, portable execution device - similar in role to 4diac FORTE but written in Python, which makes it particularly attractive for:

- Rapid prototyping of distributed IEC 61499 applications
- Edge devices and embedded Linux platforms
- AI/ML applications
- Industrial automation projects that need easy extension with custom function blocks

By consuming the same `.fbt` libraries and deployment artifacts produced by **4diac IDE**, OpenFB enables engineers to design control logic in 4diac IDE and deploy it to OpenFB-powered devices without leaving the IEC 61499 toolchain.

The project is a reworked and expanded implementation of the concepts behind DINASORE. While inspired by DINASORE, the codebase and architecture have been re-engineered:
- It speaks the same deployment protocol used by 4diac IDE and introduces (backward compatible) extensions
- Applications designed, debugged, and monitored in 4diac IDE can be executed directly on an OpenFB runtime instance
- It supports the **standard function block library** with the same interface as 4diac FORTE understand but written in [pure python](https://github.com/rtsoft-sdc/openFB/tree/main/openfb/resources/function_blocks): (Convert, Events, iec61131, Utils)
- Focus on OPC UA capabilities

The project is distributed under the **EPL 2.0** license and welcomes community contributions to advance open industrial automation.
  
## Highlights OpenFB 1.1.0:

- **Supports 4diac IDE 3.1** - native support for the latest 4diac IDE.
- **OPC UA server embedded**. It is now possible to edit input values using an OPC UA client - useful for testing and runtime tuning.
- Added new feature of exposing inputs/outputs (communication protocol extension).
- Logging improved
- Fixed issues with legacy Python 3 versions and dependencies.

For a complete overview of all improvements, please see the [CHANGELOG](https://github.com/rtsoft-sdc/openFB/blob/main/CHANGELOG.md) for this release.

### Path Toward O-PAS Compatibility:

OpenFB is being developed with the long-term goal of supporting the **Open Process Automation Standard (O-PAS)** of The Open Group. With its embedded **OPC UA** server, simple way to develop User Defined Function Block (UDFB), and IEC 61499 runtime, OpenFB is well positioned to become a building block for **O-PAS-compliant DCNs (Distributed Control Nodes)**.
