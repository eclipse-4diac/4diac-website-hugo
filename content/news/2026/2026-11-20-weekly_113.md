## Enhancements and Fixes in 4diac IDE

- **Snapshot Debugging**
  - Added support for reading function block instance states directly from the runtime
  - Introduced a dedicated launch configuration for debugging FBs using values retrieved from the runtime

- **Library Management & Export**
  - Added a preview to the library export wizard
  - Improved library export handling
    - Separated type collection from the actual export process
    - Fixed lifecycle issues during export
  - Introduced a common HTTP library package downloader infrastructure with additional tests

- **Type Management & Build**
  - Improved handling of typed subapplication instances
    - Excluded the contents of typed subapplication instance networks from project builds and XMI exports
  - Optimized opening types in editors by avoiding unnecessary type loading

- **Bulk Query Editor**
  - Migrated the Bulk Query Editor to the statically generated EMF query model

## Enhancements and Fixes in 4diac FORTE

- **OPC UA Communication**
  - Improved OPC UA client connection reliability
    - Added automatic reconnection and resubscription when subscriptions become inactive due to an unresponsive server
    - Fixed a race condition that could prevent newly added clients from connecting
  - Fixed memory leaks in `OPCUA_MGR` when creating OPC UA nodes
  - Corrected response size logging in the OPC UA receive handler

- **Network Communication**
  - Added a `tcp_parallel` communication channel supporting non-blocking, parallel connection attempts

- **I/O & Runtime Robustness**
  - Improved I/O controller shutdown handling to avoid misleading error messages when controllers are already stopped

- **Maintenance**
  - Corrected copyright attribution for HR Agrartechnik GmbH

Many thanks to all contributors for their work and their feedback!
