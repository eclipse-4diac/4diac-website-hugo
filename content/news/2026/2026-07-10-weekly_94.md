## Enhancements and Fixes in 4diac IDE

- **Monitoring & Debugging**
  - Restored existing watches automatically when starting a monitoring session
  - Enabled editing of attributes from System Explorer selections
  - Displayed internal constant variables in the System Explorer
- **Validation & OCL**
  - Introduced a project-level OCL validation builder
  - Removed legacy OCL validation infrastructure and obsolete FB OCL definitions
  - Improved quick fix availability based on project settings
- **Bulk Editor & Query Language**
  - Extended the Bulk Query Language:
    - Added support for `AttributeDeclaration`
    - Added support for Service Interface FBs and types
- **Library & Project Management**
  - Introduced a wrapper for linked library folders
- **Editor & UI Improvements**
  - Added support for disabling automatic `INITO` generation in Service Interface FBs
  - Prevented the Initial Value Editor from committing values when fields are read-only
  - Improved quick fix handling and resolved various code quality issues
  - Routed selection changes through commands for better consistency


## Enhancements and Fixes in 4diac FORTE

- Introduced the first stage of native EtherCAT support for Linux:
  - Integrated the [IgH EtherCAT Master library](https://etherlab.org/en_GB/ethercat)
  - Added the core bus handler and device layer

Many thanks to all contributors for their work and their feedback!
