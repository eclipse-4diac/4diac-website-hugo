This release introduces feature upgrades and optimization across the entire ecosystem, most notably:

- **EtherCAT Support:** Core EtherCAT integration and initial I/O function blocks in 4diac FORTE to expand fieldbus capabilities.
- **Event Flow Analysis & Editing:** A new Event Sequence view in 4diac IDE to visualize, inspect, and reorder event chains via drag-and-drop.
- **CI/CD & Project Validation:** Headless project validation with automated JSON reports alongside project-level OCL rule enforcement.
- **Editor & Workflow Enhancements:** A multi-page Bulk Editor workflow, Simple FB Event Actions tab, state breakpoints in the ECC editor, multi-device Replay Debugging, and updated Wago / RevolutionPi platform support.
- **Runtime & OPC UA Refinements:** Struct member monitoring, improved SecureChannel state reporting, and restructured management command parsing for better runtime security and stability.
