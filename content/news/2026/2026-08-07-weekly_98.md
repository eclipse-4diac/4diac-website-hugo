## Enhancements and Fixes in 4diac IDE

- **Library & Refactoring**
  - Extracted library refactoring logic from the UI plugin
  - Switched copy operations to the Eclipse LTK refactoring infrastructure
  - Simplified library deletion by removing obsolete configuration handling
  - Improved error handling in the Library Manager
  - Fixed timer function blocks after a recent regression
- **Build & Project Validation**
  - Excluded projects with library errors from export and Xtext builds
  - Added project-level markers for unresolved library dependencies
  - Improved handling of missing or invalid type names in broken projects
- **Deployment & System Configuration**
  - Fixed deployment data generation for untyped subapplications
  - Added support for restricting device profiles to supported IEC 61499 profiles
  - Introduced parsing and modeling of supported device profiles
- **Editors & Debugging**
  - Improved replay debugging interaction and timeline zoom behavior
  - Fixed execution trace handling and connection style updates
- **Model & Cleanup**
  - Added optional recursive deletion of network elements
  - Removed obsolete resource relocation support for legacy DTP files


## Enhancements and Fixes in 4diac FORTE

- **Communication & Deployment**
  - Fixed OPC UA deployment query commands
  - Added a communication layer for automatic endianness conversion supporting big-, little-, and native-endian systems
- **Runtime**
  - Fixed adapter instance handling by assigning unique IDs, preventing event conflicts in I/O modules



Many thanks to all contributors for their work and their feedback!
