## Enhancements and Fixes in 4diac IDE

- **Event Function Blocks**
  - Added the new `E_RF_TRIG` function block for combined rising/falling edge detection
  - Added generic `E_D_FF_ANY` flip-flop function block supporting arbitrary data types
  - Modernized timer function blocks by replacing deprecated event FBs with newer edge-triggering variants
  - Removed obsolete `E_MOVE` function block from the event library
  - Fixed comments and documentation typos in edge detection FBs
- **Type System & Project Handling**
  - Fixed stale type references and dependency cleanup after project dereferencing
  - Improved cleanup of FB palette listeners on disposal
- **Export & Build**
  - Refactored export builder implementation
  - Improved auto export by skipping generic types
  - Integrated CodeQL analysis into the main Maven workflow
- **Editor & Visualization**
  - Fixed transition bounds and edge direction aspect ratio handling


## Enhancements and Fixes in 4diac FORTE

- **Event Function Blocks**
  - Added `E_RF_TRIG` runtime support for detecting rising and falling boolean edges
  - Updated timer function blocks to use `E_RF_TRIG` instead of `E_SWITCH`
- **Composite FBs & Connections**
  - Fixed forwarding of generic values through internal composite FB connections
- **Platform & Code Quality**
  - Refactored FreeRTOS thread cleanup by introducing a named deleter type
  - Eliminated compiler warnings related to internal linkage

## Enhancements and Fixes in 4diac Documentation

- **Documentation Maintenance**
  - Harmonized capitalization of URL paths and file names

Many thanks to all contributors for their work and their feedback!
