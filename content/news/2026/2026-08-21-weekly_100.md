## Enhancements and Fixes in 4diac IDE

- **Library & Manifest Management**
  - Added version range editing directly in the Manifest Editor, including a dedicated configuration dialog
  - Added an **Import Libraries** button to the Manifest Editor
  - Improved the Search Reference View by showing the source code line for references
- **Struct Member Access & Manipulators**
  - Reworked struct manipulator pins to use the new member access mechanism
  - Improved navigation and connection following for member access pins
  - Removed obsolete multiplexer/demultiplexer edit parts, property sheets, and model elements
  - Simplified handling of visible multiplexer/demultiplexer children and legacy format compatibility
- **Configurable Function Blocks**
  - Introduced a unified instance property sheet for configurable FBs, combining instance and type configuration
  - Removed obsolete dedicated property sheets for multiplexer and configurable `MOVE` FBs
  - Simplified configurable FB configuration handling
- **Usability & UI**
  - Prevented property sheets from stealing focus when selections change
  - Fixed event action table layout on Windows
  - Improved UI independence of FB shape handling
- **Other**
  - Added register communication support for Wago 750-636
  - Corrected the comment for `SPLIT_LTOD`
  - Further reduced UI and RGB dependencies in the utility/model code


## Enhancements and Fixes in 4diac FORTE

- **Timer Function Blocks**
   - Fixed a regression in the standard timer function blocks `E_PULSE`, `E_TOF`, `E_TON`, `E_TONOF`, and `E_TP`.

Many thanks to all contributors for their work and their feedback!
