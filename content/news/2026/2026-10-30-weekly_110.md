## Enhancements and Fixes in 4diac IDE

- **Bulk Editor & Querying**
  - Significantly extended the graphical Bulk Query Editor
    - Replaced the Zest viewer with a GEF-based editor, adding zoom, selection feedback, direct editing, and keyboard shortcuts
    - Added support for querying connections, connection attributes, subapplication hierarchies, function FBs, and composite FBs
    - Extended query constraints with AND/OR combinations, negation, and mixed constraint types
    - Improved constraint validation, chaining, and editing
  - Integrated graphical queries into the Bulk Editor's search functionality, replacing the previous search tab
  - Added loading and saving of queries, including support for opening query files from the System Explorer
  - Improved undo/redo handling and management of unsaved changes
  - Improved context menus and graphical layout

- **Replay Debugging**
  - Extended the event timeline and state comparison views
    - Added event numbering and improved keyboard navigation
    - Added shortcuts for comments and state comparisons
    - Added a comment table linked to timeline commands
    - Improved state comparison visualization, including selection highlighting and clearer change indicators
    - Improved table layout and readability
  - Improved interaction with timeline events and comparison markers

- **ECC Editor**
  - Improved transition routing to avoid overlapping unrelated states
    - Automatically adjusts bendpoints when transitions intersect other states
    - Caches routing results to avoid unnecessary recalculations

- **EtherCAT Support**
  - Added an EtherCAT ESI import wizard
    - Generates device and module FB types from ESI files
    - Uses type library packages and `ForteTypeOverride` for deployment

- **AsciiDoc Documentation Editor**
  - Added keyboard shortcuts for toolbar commands
  - Added tooltips showing available shortcuts
  - Improved link insertion using the `link:URL[display text]` syntax
  - Improved command handling and editor context activation

- **Graphical Editors & Navigation**
  - Improved breadcrumb editor handling
    - Centralized editor closing and breadcrumb updates when model elements are deleted
    - Removed obsolete editor listeners and adapters
    - Improved navigation into expanded subapplications
  - Fixed opening mapped typed subapplications from resources
  - Fixed navigation errors when returning to target pins
  - Fixed an exception when closing an instance cell editor
  - Prevented expansion of array-of-struct pins

- **Model Import & Export**
  - Added a model import/export round-trip test suite using reference fixtures
  - Fixed attribute import/export for device, resource, and segment types
  - Reduced unnecessary type lookups in XML export and dynamic type deployment

- **Internationalization & Maintenance**
  - Continued externalizing user-facing strings across IDE components
    - GEF, Model UI, Hierarchy Manager, Model Search, Service Sequence Editor, and others
  - Migrated additional Structured Text and Model Search components to Eclipse Platform's `ILog`
  - Updated Git attributes for 4diac model files
  - Removed the obsolete Zest dependency from the target platform

## Enhancements and Fixes in 4diac FORTE

- **Network Communication**
  - Fixed TCP and UDP receive error handling to correctly identify closed connections and prevent repeated receive failures
  - Fixed socket resource leaks in the TCP listen channel during connection lifecycle changes and error handling

- **Tracing & Replay Debugging**
  - Moved CTF tracer ownership to the Event Chain Execution Thread (ECET)
    - Improved tracing of event execution and instance data
    - Avoided unnecessary tracing for internal FBs and devices
  - Reduced tracing overhead by removing input and output data trace events

Many thanks to all contributors for their work and their feedback!
