## Enhancements and Fixes in 4diac IDE

- **Structured Text & Refactoring**
  - Improved handling of ST imports
    - Automatically removed empty imports and stripped unnecessary whitespace
    - Fixed exceptions caused by empty imports
  - Added validation for package mismatches between ST source files and their enclosing types
  - Fixed ST refactoring to correctly select an Xtext editor instead of a generic text editor
  - Restricted Xtext resource caching to Xtext resources to prevent potential concurrency issues
- **Internationalization & Localization**
  - Externalized user-facing strings to prepare additional IDE components for translation
    - FB Type, Data Type, Attribute, and Bulk Editors
    - Contracts and Communication Generation
    - ELK integration, including commands, menus, tooltips, and preferences
- **FB Interpreter**
  - Fixed evaluator executor lifecycle management
  - Ensured evaluator resources are properly closed when interpreter sessions end
- **Library & Type Management**
  - Corrected missing and incorrect package declarations in the type library
  - Improved handling of Eclipse Milo dependencies
  - Suppressed unnecessary file-not-found log messages caused by stale workspace state when loading manifest files
- **Documentation & Issue Reporting**
  - Fixed IDE documentation generation to correctly ignore Hugo front matter
  - Improved GitLab issue reporting by sending report data in the request body


Many thanks to all contributors for their work and their feedback!
