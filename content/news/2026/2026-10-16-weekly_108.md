## Enhancements and Fixes in 4diac IDE

- **Documentation Editor**
  - Improved the AsciiDoc formatting toolbar
    - Switched to Mylyn AsciiDoc templates for more consistent formatting
    - Fixed bold and superscript formatting
    - Added support for inserting links and admonitions

- **Validation & Type Handling**
  - Added validation for circular struct member references
    - Detects indirect circular dependencies and reports the involved type chain
    - Supports navigation to the affected model elements
  - Improved handling of library element dependency updates to prevent reentrant operations
  - Fixed potential exceptions when refreshing pin information with outdated data

- **Editor Stability**
  - Improved multi-page editor handling by decoupling automatic page closing from type updates
  - Fixed potential exceptions when editor pages have already been disposed

- **Library Management**
  - Improved library download testing with a mock downloader
  - Fixed version selection and manifest handling in library download tests
  - Ensured library import tests restore their original test state
  - Improved GitLab integration by retrieving lists in pages of 100 entries

- **Deployment**
  - Improved OPC UA deployment response handling with additional validation and error handling
  - Removed redundant deployment menu labels

- **Internationalization**
  - Externalized user-facing strings in additional IDE components
    - FBRT and FORTE launchers
    - FMU integration and application visualization
    - Replay debugging and bootfile generation
    - IEC 61499 deployment

- **Platform & Code Maintenance**
  - Updated to Eclipse 2026-12 and refreshed major dependencies
  - Moved the target platform definition into a separate bundle
  - Continued migrating IDE components to Eclipse Platform's `ILog`, reducing dependencies on the utility plugin

## Enhancements and Fixes in 4diac FORTE

- **Connection Handling**
  - Added support for nested delegating connections, including negated member connections
  - Added a helper function for retrieving data type identifiers from data connections

- **Performance**
  - Optimized escaped XML sequence lookup


Many thanks to all contributors for their work and their feedback!
