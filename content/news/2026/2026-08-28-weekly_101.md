## Enhancements and Fixes in 4diac IDE

- **Visualization & Event Sequences**
  - Added an Event Sequence View with drag-and-drop reordering
  - Added FB network lane and topology graphs
  - Redesigned self-loop visualization
- **OCL Validation**
  - Reworked OCL dependencies and parsing
  - Improved validation after project reference changes
  - Improved marker cleanup and handling when validation is disabled
  - Added build-path projects to the OCL validation extent
  - Added additional OCL validation tests
- **Type & Editor Handling**
  - Improved handling of types without backing files
  - Fixed hierarchy manager drop validation
  - Improved attribute target validation for internal variables
  - Fixed asynchronous refresh issues in the FB Debug View
- **Build & Tooling**
  - Added project-wide Ant checks with shared reporting and JSON output
  - Renamed and reorganized Ant check infrastructure
- **Function Blocks & Storage**
  - Improved `RampLimitFS` initialization and `WITH` lists
  - Added `qAtZero` and `qAtFull` limit indicators
  - Fixed service definitions and documentation for `ARTimeOut`, `ATimeOut`, `E_DELAY`, and `E_RDELAY`


## Enhancements and Fixes in 4diac FORTE

- **Monitoring**
  - Added monitoring support for struct members
  - Reworked watch handling to use name identifiers and `std::span`
- **Wago & Function Blocks**
  - Added register communication support for Wago 750-636
  - Regenerated `RampLimitFS` with the corrected initialization and new limit indicators
- **OPC UA**
  - Improved SecureChannel diagnostics by reporting the actual connection state instead of misleading open-state messages

## Enhancements and Fixes in 4diac Documentation


- **Wago**
  - Added documentation for register communication with Wago modular I/O.

Many thanks to all contributors for their work and their feedback!
