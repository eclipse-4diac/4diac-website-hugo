## Enhancements and Fixes in 4diac IDE

- **Documentation Editor**
  - Extended the AsciiDoc formatting toolbar
    - Added an image insertion dialog with support for managing images in the `.assets` folder
    - Added buttons for inserting source code blocks and function block type macros
    - Improved the toolbar layout and restricted its visibility to the AsciiDoc Source tab

- **Type Export & Code Generation**
  - Improved FORTE NG export of function FBs
    - Generated separate Structured Text implementations to reduce function call overhead
    - Removed unnecessary event accessors
  - Added an option to export library types as Service Interface Function Blocks (SIFBs)
  - Restricted supported types for SIFB export

- **Library & Type Management**
  - Improved library cache handling to prevent concurrent update issues
  - Fixed library registration after archive extraction, including cases without filesystem notifications
  - Improved reliability of library downloads and extraction

- **Structured Text & Refactoring**
  - Improved struct member reference resolution to respect type visibility and scope
  - Fixed ST refactoring to use the appropriate language editor
  - Improved standalone ST resource registration and test reliability
  - Optimized resource change handling by filtering irrelevant project changes

- **Function Block Library**
  - Added interface declarations for generic `E_D_FF_ANY_1..5` service interface FBs
    - Native 4diac FORTE implementations are still required
  - Added OPC UA function blocks for node creation
  - Corrected the `E_RESTART` cold restart service sequence to use the `COLD` output event

- **Internationalization**
  - Continued externalizing user-facing strings to prepare the IDE for localization: Library, Application, Validation, Type Management, FB Type Editor, Service Sequence Editor, Export, Model Search, GitLab, and other IDE components

- **Code Quality & Maintenance**
  - Continued migrating IDE components to Eclipse Platform's `ILog`
  - Simplified Maven build configuration and consolidated dependencies in the target platform
  - Improved editor robustness when views are closed or disposed
  - Removed obsolete Eclipse Milo compatibility plugins following improvements in Milo 1.1.8

## Enhancements and Fixes in 4diac FORTE

- **OPC UA**
  - Added functions for OPC UA node creation

- **Event Handling**
  - Improved `E_TRIG` to execute triggered events sequentially
    - Prevents overloading the event queue
    - Ensures `CNF` is emitted only after all triggered events have been processed

- **Code Generation**
  - Regenerated function implementations using the latest FORTE NG exporter improvements

## Enhancements and Fixes in 4diac Documentation

- **Developer Documentation**
  - Added documentation for the type management test suite
    - Explains the test infrastructure, fixtures, execution, and assertions
    - Provides guidance for running and extending the tests

- **OPC UA Deployment**
  - Added a tutorial for installing the optional OPC UA Deployment feature in 4diac IDE

Many thanks to all contributors for their work and their feedback!
