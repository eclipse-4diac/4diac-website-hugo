## Enhancements and Fixes in 4dtheiac IDE

- **Wago 750-636**
  - Improved register communication:
    - Added `CurrentControlOn` support for dependent registers
    - Made automatic password reset configurable
    - Renamed the adapter for consistency
- **Type & Library Management**
  - Improved ST refactoring by avoiding updates to invalid error types
  - Ensured the Library Element Provider always loads up-to-date elements
  - Added error library elements when loading library resources fails
- **Deployment & Compatibility**
  - Added support for package-qualified `ForteTypeOverride` names in FORTE deployment
  - Improved handling of legacy struct demultiplexer parameters and connections
  - Fixed deployment device initialization to avoid duplicate entries
  - Added invisible connections when reordering event sequences for untyped subapplications
- **Function Blocks & Documentation**
  - Improved arithmetic FB input descriptions with proper mathematical terminology
  - Updated the splash screen for the 3.3 release
- **Java & Build Infrastructure**
  - Upgraded all plugins to Java 25
  - Updated build and test plugin configuration for the 3.3 release
  - Bumped versions for the 3.4 release train
  - Removed an obsolete validation bundle activator
  - Added GitHub Copilot instructions
  - Fixed Java 25-related warnings

## Enhancements and Fixes in 4diac FORTE

- **OPC UA**
  - Fixed `UA_ServerConfig` initialization to prevent the logger pointer from being incorrectly assigned to the server context
- **Management Commands**
  - Fixed command parsing for connection sources ending with an empty segment, as used for unnamed IEC 61131-3 function return values
  - Added Copilot review instructions


Many thanks to all contributors for their work and their feedback!
