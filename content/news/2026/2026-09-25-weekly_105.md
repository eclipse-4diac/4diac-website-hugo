## Enhancements and Fixes in 4diac IDE

- **EtherCAT Support**
  - Added EtherCAT types to the I/O type library
    - Introduced `ECController`, `ECBusAdapter`, and device/module configuration structures
    - Added the `RevisionNo` attribute in preparation for ESI import support
- **Struct Member Handling**
  - Added refactoring support for creating struct members directly from connection dragging
  - Added a shortcut for struct member refactoring
  - Added support for struct member connections across subapplications
  - Extended automated tests for struct pin refactoring
- **Graphical Editors & Usability**
  - Improved positioning and movement of elements inside expanded and nested subapplications
  - Improved the context-sensitive New menu
    - Restricted comment creation to selections on the editor background
    - Disabled invalid creation actions when connections are selected
    - Hidden the menu when no valid creation actions are available
  - Improved coordinate handling in graphical editors
  - Preserved ECC transition bendpoint layouts when moving states
- **Subapplications & Refactoring**
  - Fixed undo/redo behavior for operations involving expanded subapplications and groups
  - Fixed global constant imports for subapplication interface pins
- **Library & Type Management**
  - Optimized remote manifest dependency lookup and corrected manifest path handling
  - Added common XML resource loading options
- **Robustness**
  - Improved handling of value updates when interface elements are deleted during asynchronous calculations


## Enhancements and Fixes in 4diac FORTE

- **OPC UA**
  - Updated [open62541](https://open62541.org/) to version 1.5.8

Many thanks to all contributors for their work and their feedback!
