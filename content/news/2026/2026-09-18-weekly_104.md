## Enhancements and Fixes in 4diac IDE

- **Graphical Editors & Usability**
  - Redesigned the double-click menu in FB network editors
    - Added dedicated buttons for creating subapplications and comments
    - Improved menu positioning and scrolling behavior
  - Reorganized the Source menu with a new submenu for creating subapplications, comments, and groups
  - Improved menu icon handling to reduce duplication
- **ECC Editor**
  - Added direct state creation by double-clicking on an empty ECC canvas
    - States are created only when the inline name editor is confirmed
    - Cancelling the editor leaves the model unchanged
- **4diac FORTE Type Export**
  - Added support for preserving additional source directories during type export cleanup
  - Added configuration of additional source directories in the type export properties
  - Integrated preserved source directories into generated CMake files
  - Added refactoring support for additional source directories
  - Prevented user-managed source directories from being placed inside directories generated by the 4diac FORTE export filter
- **Structured Text**
  - Fixed parsing of time literals in the ST parser and value converter
  - Regenerated the ST parser and updated its build configuration
- **Library & Type Management**
  - Improved library element loading and saving through resource-based access
  - Extended library element resources with interface-only loading, type entry support, and dependency handling
  - Unified error library element creation across the type library infrastructure
  - Improved URI handling and error reporting for library downloads
  - Fixed handling of unresolved library dependencies
- **Function Block Library**
  - Improved `DualHysteresis`
    - Added direct transitions between `UP` and `DOWN` to correctly handle large input changes within a single event
    - Improved threshold documentation and handling of negative `DEAD` and `HYSTERESIS` parameters
- **Code Quality & Maintenance**
  - Added a Checkstyle rule requiring a newline at the end of source files
  - Updated the formatter and corrected affected files
  - Cleaned up obsolete importer/exporter APIs and marked internal APIs accordingly


Many thanks to all contributors for their work and their feedback!
