## Enhancements and Fixes in 4diac IDE

- **Library Management & Export**
  - Added a library export wizard
    - Supports case-insensitive pattern matching
    - Prompts users to save modified resources before exporting
  - Fixed a race condition when replacing stale error type entries
  - Corrected the FIELDBUS_SIGNAL package name
- **Documentation Editor**
  - Added a formatting toolbar to the AsciiDoc Description Editor
    - Bold and italic formatting
    - Subscript and superscript
      - Ordered and unordered lists
      - Document title and heading levels 1–5
- **Subapplications & Validation**
  - Added instance and override attributes for typed subapplications
  - Added validation for adapter connection cardinality
- **Device Support**
  - Added support for Revolution Pi devices
- **Internationalization**
  - Externalized user-facing strings in additional IDE components to prepare them for localization: 
    Resource editing, system configuration, Library UI, segment editing, Subapplication Type Editor, System Management UI, and Contract Specification Editor
- **Code Quality & Maintenance**
  - Migrated logging across numerous IDE components to Eclipse Platform's ILog
    - Simplified logging infrastructure and reduced dependencies on the utility plugin
  - Refactored shared UI widgets and improved user-facing messages


## Enhancements and Fixes in 4diac FORTE

- **InOut Connections**
  - Fixed the handling of generic source ports for InOut connections
  - Fixed missing management command responses when creating InOut connections
  - Added tests for InOut connection handling

## Enhancements and Fixes in 4diac FBE

- **Dependencies**
  - Updated [open62541](https://open62541.org/) to version 1.5.8


Many thanks to all contributors for their work and their feedback!
