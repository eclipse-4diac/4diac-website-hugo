## Enhancements and Fixes in 4diac IDE

- **Library Management**
  - Extended library manifest validation
    - Added checks for library names, version information, version ranges, and include/exclude patterns
    - Improved error reporting for missing or invalid version declarations
  - Improved library package downloading
    - Unified discovery of library downloader providers
    - Fixed stale library cache entries, particularly on macOS
  - Improved library element hashing by excluding source comments from hash calculations

- **Structured Text & Type Management**
  - Extended the type model and ST parser to preserve Structured Text source elements and comments during import/export
  - Improved adapter attribute handling
    - Preserved attributes across import/export and save/reload cycles
    - Ensured consistent editing in interface editors and FB networks

- **Bulk Query Editor**
  - Added indicators for hidden query nodes
  - Fixed query viewer updates when opening `.query` files
  - Extended the query model in preparation for constraint declarations

- **Graphical Editors & Usability**
  - Fixed opening mapped subapplications and composite FB instances from resources
  - Improved breadcrumb synchronization to prevent incorrect model references and potential loss of changes
  - Fixed resource deletion issues after editors had been opened
  - Improved handling of nested containers

- **Deployment & Maintenance**
  - Improved OPC UA deployment client configuration to support higher message limits
  - Continued migrating IDE components to Eclipse Platform's `ILog`
  - Continued preparing user-facing strings for localization
  - Removed obsolete dependencies and simplified platform configuration

## Enhancements and Fixes in 4diac FORTE

- **Function Blocks**
  - Added the generic `GEN_E_D_FF_ANY` implementation for multi-channel data latches
    - Supports arbitrary and mixed data types
    - Generates an output event when at least one input differs from its latched value
  - Fixed missing `MIN` and `MAX` dependencies in `LIMIT`

- **I/O Support**
  - Improved EtherCAT device handle management
  - Fixed process interface deinitialization to reliably report the not-ready state
  - Cleaned up the I/O interface infrastructure
  - Removed obsolete hardware support modules: Conmeleon C1, I2C Dev, Lego Mindstorms EV3, MLPI, Odroid, PiFace, Raspberry SPS, and uMIC
  - Removed unused SysFS I/O support classes

- **Runtime & Communication**
  - Fixed default initialization of derived data type variants with affected Clang versions
  - Fixed UDP listen channels retaining outdated connection states
  - Corrected logging format issues in communication and replay components

Many thanks to all contributors for their work and their feedback!
